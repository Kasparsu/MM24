## 🗂️ Topics Covered

> 📮 The router learns that a URL is not just a path, and the project gets its first page
> that sends data back to the server instead of only receiving it.

### 1. ✂️ A query string is not part of the path

`/forms?name=kaspar` and `/forms` are the same page. The router was comparing the whole
`REQUEST_URI`, so the moment a form appended `?name=…` nothing matched and every request
fell through to 404.

```php
public function __construct(private $path, private $method)
{
    $this->path = parse_url($this->path, PHP_URL_PATH);
}
```

`parse_url` with `PHP_URL_PATH` returns only the part before the `?`. Doing it once in the
constructor means every route comparison afterwards is clean — the fix lives in one place
rather than in every `case`.

Docs: <https://www.php.net/manual/en/function.parse-url.php>

![Query string](https://api.memegen.link/images/ackbar/A_query_string_in_the_path/It's_a_trap.png)

### 2. 📨 GET and POST

Both send data; they differ in *where* it rides and *what it means*.

| | GET | POST |
|---|---|---|
| Data travels in | the URL | the request body |
| Visible in the address bar | yes | no |
| Bookmarkable / shareable | yes | no |
| Safe to repeat | yes | no — resubmits |
| Use for | searching, filtering, paging | creating, changing, deleting |

```html
<form method="POST" action="/forms">
  <input type="text" name="title">
  <button>Save</button>
</form>
```

In PHP the two arrive in different superglobals — `$_GET` and `$_POST` — which is why the
router has to care about the method, not only the address.

![GET and POST](https://api.memegen.link/images/both/GET_or_POST/Why_not_both.png)

### 3. 🧾 The forms page

`views/forms.php` was added as somewhere to actually try this: a form that posts back to
the same address, and a dump of what arrived. Seeing `$_POST` printed is the fastest way
to understand that the browser sends *names*, not variables — `name="title"` on the input
is what becomes the key.

## ✅ Takeaways

1. **Match on the path, not the whole URI.** `parse_url(..., PHP_URL_PATH)` strips the
   query string, and doing it once in the constructor fixes every route at the same time.
2. **GET is for asking, POST is for changing.** Bookmarkable and repeatable versus not.
3. **`name=` is the contract.** What the browser sends is keyed by the input's name.
