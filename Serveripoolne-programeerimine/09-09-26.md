## 🗂️ Topics Covered

### 1. 🧩 Functions: Naming a Piece of Code

A function is a block of code you give a name, so you can run it whenever you like instead of
repeating it.

```php
function hello(): void {
    var_dump('Hello');
}

hello();
hello();   // call it as many times as you want
```

**`: void`** is the **return type**: this function promises to give nothing back. Proof:

```php
$hi = hello();
var_dump($hi);   // NULL
```

It printed, but it **returned** nothing. Printing and returning are different things.

### 2. 🎛️ Parameters & Default Values

```php
function helloName($name = 'Nameless') {
    var_dump("Hello, $name!");
}

helloName('Kaspar');   // Hello, Kaspar!
helloName('Martin');   // Hello, Martin!
helloName();           // Hello, Nameless! : default kicks in
```

A **parameter** is a value the function takes in. Giving it a **default** makes the argument
optional.

**Several parameters, in order:**
```php
function helloNameAndAge($name, $age) {
    var_dump("Hello, $name! You are $age years old!");
}

helloNameAndAge('Kaspar', 33);
helloNameAndAge('Pets', 78);
```

Arguments are matched **by position**: first argument to first parameter, and so on.

### 3. ↩️ `return`: Giving a Value Back

```php
function cube(int $a): int|string {
    if ($a < 0) {
        return 'No negative!';
    }
    return $a * $a * $a;
    var_dump('BLAAAAA');   // never runs
}

var_dump(cube(4));   // 64
```

Several things at once here:

| Feature | What it means |
|---|---|
| `int $a` | **Typed parameter**: this must be an integer |
| `: int\|string` | **Union return type**: returns *either* an int or a string |
| early `return` | Leaves the function immediately |
| `var_dump('BLAAAAA')` | **Unreachable.** Nothing after a `return` runs. |

**A returned value is just a value**: use it anywhere:
```php
$answer = cube(5);
$text = "Cube of 5 is $answer!";
echo $text;
```

> ⚠️ Passing the wrong type (`cube('asdasd')`) is where the declared `int` earns its keep:
> PHP complains instead of quietly doing something strange.

### 4. 🎭 Anonymous Functions & Arrow Functions

A function doesn't need a name. It can be stored in a variable like any other value:

```php
$test = function () {

};
var_dump($test);   // object(Closure)
```

**Where this is actually useful**: handing a function to another function:

```php
$numbers = [1, 2, 3, 4, 5];

$squares = array_map(function ($n) {
    return $n * $n;
}, $numbers);
```

`array_map` walks the array, runs your function on each element, and gives back a new array of
the results.

**The short form**: arrow functions, for one-expression cases:
```php
$squares = array_map(fn ($n) => $n * $n, $numbers);
```

Identical behaviour. `fn` implies the `return`, so there are no braces and no `return` keyword.

### 5. 📦 Classes & Objects: the First Look

A **class** is a template. An **object** is a thing built from that template.

```php
class Box {
    public $width;
    public $height;
    public $length;
    public $isOpen = false;
    public $hasBeenOpened = false;

    public function open() {
        $this->isOpen = true;
        $this->hasBeenOpened = true;
    }

    public function close() {
        $this->isOpen = false;
    }

    public function volume() {
        return $this->height * $this->length * $this->width;
    }
}
```

**Vocabulary:**

| Term | Meaning |
|---|---|
| **Property** | A variable belonging to the object (`$width`, `$isOpen`) |
| **Method** | A function belonging to the object (`open()`, `volume()`) |
| **`$this`** | Inside a method, the object it was called on |
| **`->`** | Reach into an object for a property or method |

Properties can have **default values** (`$isOpen = false`), same as parameters.

**Making objects:**
```php
$box1 = new Box();
$box1->width  = 10;
$box1->height = 20;
$box1->length = 30;
$box1->open();
var_dump($box1);
var_dump($box1->volume());   // 6000

$box2 = new Box();
$box2->width  = 30;
$box2->height = 40;
$box2->length = 50;
var_dump($box2->volume());   // 60000
var_dump($box1);             // box1 is untouched
```

**The point:** one class, two completely independent objects. `$box2` has its own copy of every
property, and opening `$box1` doesn't open `$box2`. `volume()` works on whichever object you
called it on, because `$this` refers to that object.

## ✅ Takeaways

1. **Printing is not returning.** A `void` function gives back `NULL`.
2. **Default parameter values make arguments optional**; arguments match **by position**.
3. **Nothing after `return` runs.**
4. **Type declarations** (`int $a`, `: int|string`) make PHP catch your mistakes for you.
5. **Functions are values**: store them, pass them to `array_map`, shorten with `fn () =>`.
6. **A class is a template; an object is an instance.** `$this->` is how an object reaches
   its own properties, and each object keeps its own.
