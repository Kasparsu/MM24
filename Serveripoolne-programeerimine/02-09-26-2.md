### 1. 🌐 PHP Runs in Two Places

PHP does two distinct jobs:

- **Web pages / web server**: the usual case
- **Command-line programs**: run a `.php` file directly from the terminal

Same language, two ways to reach it.

---

### 2. 🚀 The Built-in Development Server

You don't need Apache or nginx to start. PHP ships its own development server:

```bash
php -S localhost:8000
```

- `-S` (capital S): think **S for server**
- `localhost:8000`: the address it listens on

It prints `PHP development server started…`. **Ctrl+click** the address in the terminal and
your browser opens on it, or type `localhost:8000` into the address bar yourself.

**To stop it:** `Ctrl+C`. The server keeps running and holding the terminal until you do: it
does not stop on its own, and closing the window may leave it running in the background.

> ⚠️ `Ctrl+C` stops the currently running program in that terminal. Get used to it now; you'll
> need it constantly.

### 3. 💬 Comments

```php
// a single-line comment

/*
   a block comment
   over several lines
*/

/**
 * a doc-style block
 */
```

Comments do **nothing** to the program: PHP ignores them entirely. They exist for people.

**What they're for:**
- Explaining a genuinely tricky piece of logic
- Notes to yourself. Come back in two years and you'll have no idea what that block does
- Notes to colleagues: most code is written in collaboration
- Explaining *why* something odd is there, e.g. a workaround for a specific bug

### 4. 💲 Variables, and Why the Dollar Sign

In JavaScript you declared variables with `let`, `const` or (historically) `var`. **PHP has no
keyword.** Instead, every variable name starts with `$`:

```php
$name = "John Doe";   // variable to store the name
$age  = 30;           // variable to store the age
echo $age;
```

The `$` is what marks it as a variable. It feels alien coming from JavaScript, but it's
mandatory and it's the whole declaration.

**What a variable actually is:** a name pointing at a place in memory (RAM). Rather than
repeating a value (or a long calculation) everywhere, you store it once and refer to it by
name. It's the same idea as `x` in maths: a stand-in whose value you can look up or change.

**And it *varies*: that's the point:**
```php
$age = $age * 2 * 3 * 4 * 5 * 6 * 7 * 8 * 9 * 10;
echo $age;
```
You don't need to know the answer. The program recalculates and the variable now holds the new
value.

**Whitespace doesn't matter.** Spaces around `=`, blank lines, indentation: PHP ignores all of
it. It's for readability, and you should still use it.

**PHP can do arithmetic, and that's what makes it a programming language:**
```php
echo 2 + 2;   // 4
```
Contrast with a markup language: write `2 + 2` in HTML and you get the text `2 + 2`. There's no
mechanism to make it calculate. Big numbers are fine too: PHP handles them without complaint.

### 5. 🔢 Types & `var_dump()`

A variable can hold any type, and can be reassigned to a different one:

```php
$test = 10;              // int
$test = 3.1;             // float
$test = "Hello World";   // string
$test = "õpilane";       // strings handle Estonian characters fine
$test = "💩";            // …and emoji
$test = true;            // bool
$test = false;
$test = null;            // null: deliberately nothing
$lol;                    // declared but never assigned

var_dump($test);
var_dump($lol);
```

**`var_dump()` is the tool to know.** `echo` prints a value; `var_dump()` prints the value
**and its type** (and, for strings, the length). When something behaves oddly, `var_dump()` is
how you find out what you're actually holding.

**Arrays and objects:**
```php
$test = [1, 2, "three", true];   // mixed types in one array is allowed
var_dump($test);

$test = new stdClass();
$test->name = "John";            // -> to reach a property, not .
var_dump($test);
```

**Strict comparison:**
```php
$num1 = 10000000000;     // int
$num2 = "10000000000";   // string
var_dump($num1 === $num2);   // false
```
They look identical printed. `===` compares **value and type**, so a number and a string of
that number are not equal. This distinction causes a great deal of confusion later, which is
why it's introduced now.

### 6. 🔄 Committing From VS Code

The Git workflow was done through the VS Code source-control panel rather than the terminal:

1. **Stage** the changed files (the `+` next to each file)
2. Write a commit message and **Commit**
3. **Sync / Push**: the blue button

Afterwards, GitHub's `main` branch is at the same state as your local `main`.

## ✅ Takeaways

1. **`php -S localhost:8000`** is all you need to serve a page. `Ctrl+C` stops it.
2. **Every PHP variable starts with `$`.** No `let`, no `const`.
3. **A variable is a name for a place in memory**: store once, reuse, and let it change.
4. **`var_dump()` shows type, `echo` doesn't.** Reach for it whenever something is strange.
5. **`===` compares type as well as value**: `10000000000 !== "10000000000"`.
6. **Comments are for humans**, especially future you.
