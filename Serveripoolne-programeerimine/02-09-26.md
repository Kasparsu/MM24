## 🗂️ Topics Covered

### 1. 🐘 Hello, World: the First PHP File

The whole output of the session, committed at the end:

```php
<?php
echo "Hello, World!";
?>
```

**What each part is doing:**

| Part | Meaning |
|---|---|
| `<?php` | Opening tag. Everything after it is PHP, not plain text. |
| `echo` | Write this out |
| `"Hello, World!"` | A string: text goes in quotes |
| `;` | Statement terminator. PHP wants one after every statement. |
| `?>` | Closing tag |

**To see it in a browser**, from the directory containing the file:

```bash
php -S localhost:8000
```

then open `localhost:8000`. `Ctrl+C` in the terminal stops the server.

## ✅ Takeaways

1. **`<?php … ?>`** wraps PHP code; `echo` prints; every statement ends with `;`.
2. **`php -S localhost:8000`** serves the current directory: no Apache needed.
3. **Everyone on the same toolchain** before the real material starts. `--force` fixes a
   half-configured Git install.
