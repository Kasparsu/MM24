## 🗂️ Topics Covered

### 1. 📄 A Second Page

With the blog template split into partials, the front page is `index.php`. Adding another page
is now cheap:

1. **Copy `index.php` → `us.php`**
2. **Remove the sections that shouldn't be there.** The home page has a hero banner and a
   featured-post block; the "us" page doesn't, so those two includes come out.
3. Everything the two pages share (header, nav, footer) is still a single file each.

**Reach it at** `localhost:8000/us.php`.

> 💡 This is the payoff from splitting into partials. Making a second page meant deleting two
> lines, not copying 750 lines of markup and editing them.

---

### 2. 🧭 Making the Navigation Work

The template ships with placeholder links:

```html
<a href="#">Home</a>
```

`href="#"` is a link to nowhere: it looks right and does nothing. Point them at real paths:

| Link | `href` |
|---|---|
| Home | `/` |
| Us | `/us.php` |

A leading `/` means "from the site root", so the same nav works from any page. Refresh and the
navigation actually moves between the two pages.

---

### 3. 🧹 Format Document

A practical aside: markup pasted or copied around ends up with inconsistent indentation, which
makes it hard to see where a section begins and ends.

**Right-click → Format Document** in VS Code re-indents the whole file. Worth doing before you
try to read something unfamiliar: most of "this file is confusing" is often just bad
indentation.

![Format document](https://api.memegen.link/images/drake/Reading_750_unindented_lines/Right--click_%E2%86%92_Format_Document.png)

---

### 4. 🏷️ Page Titles

The two pages also need to differ in the `<title>`: the text the browser tab shows. Since the
`<head>` lives in the shared `header.php`, the title has to be passed in rather than hard-coded,
which is the first hint of why partials will soon need **variables** rather than being static
chunks of HTML.

## ✅ Takeaways

1. **A second page is a copy plus a couple of deleted includes** once the template is split up.
2. **`href="#"` goes nowhere.** Use root-relative paths (`/`, `/us.php`) so links work from
   any page.
3. **Format Document** before trying to read unfamiliar markup.
4. **Shared partials need per-page values**: the `<title>` is the first thing that can't stay
   hard-coded.
