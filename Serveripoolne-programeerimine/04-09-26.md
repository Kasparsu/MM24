### 1. ➗ Arithmetic Operators

The obvious four work as expected, on literals or variables:

```php
$test = 10 + 2;
$test = 10 - 2;
$test = 10 * 2;
$test = 10 / 2;
```

**Compound assignment** — the shorthand. These two lines do exactly the same thing:

```php
$test = $test - 1;
$test -= 1;        // same thing, shorter
```

Take the current value, subtract one, store the result back. All four have a compound form:

```php
$test -= 1;
$test += 1;
$test *= 2;
$test /= 2;
```

**Increment and decrement** — shorter still, for the very common "add one / subtract one":

```php
$test++;   // same as $test += 1, same as $test = $test + 1
$test--;
```

### 2. 🔢 Modulo — the `%` That Isn't a Percent

```php
$test = 10 % 3;   // 1
```

It **looks** like a percent sign but means **remainder after division**. 10 ÷ 3 goes 3 times
(9), and 10 − 9 = **1** left over.

**Why you'd want it:**

| Use | How |
|---|---|
| Does this divide evenly? | Remainder `0` = yes, anything else = no |
| Is this number even or odd? | `$n % 2` — `0` is even, `1` is odd |

### 3. 🔺 Precedence, Powers and Maths Functions

Normal mathematical precedence applies, and brackets override it:

```php
$test = (10 + (2 - 3) * 4) / 2;
```

> 📌 Unlike handwritten maths, there's only **one kind of bracket**. Nest ordinary parentheses
> as deep as you need — no square or curly variants.

**Exponentiation** is `**`:

```php
$test = 2 ** 4;    // 16
$test **= 3;       // compound form exists too
$test %= 2;
```

**Anything beyond that lives in a function.** Sine, cosine, logarithms, roots — all there:

```php
$test = sqrt(16);   // 4
```

The full list is in the manual rather than something to memorise.

| Link | What it is |
|---|---|
| <https://www.php.net/manual/en/ref.math.php> | PHP math functions |

> ⚠️ Note that none of this prints anything on its own. Assigning to `$test` over and over just
> overwrites it — add `var_dump($test)` when you want to see a result.

### 4. 🔤 Strings — Quotes, Joining, Interpolation

```php
$test = 'hello';
$test = 'hello' . ' world';   // . joins strings
$test .= '!';                 // compound form, same as the other operators
```

**Concatenation uses `.`**, not `+`.

**Two ways to build a sentence:**

```php
$name = 'Kaspar';
$age  = 33;

$test = $name . ' is ' . $age . ' years old.';   // concatenation
$test = "$name is $age years old.";              // interpolation
```

**This is the difference between the quote types:**

| Quotes | Behaviour |
|---|---|
| `'single'` | Literal. `$name` stays the text `$name`. |
| `"double"` | Variables are **interpolated**, and escape sequences work |

```php
$test = "hello\n\nworld";   // \n is a newline — only in double quotes
```

**A curiosity to finish:**

```php
$letter = 'a';
$letter++;
var_dump($letter);   // 'b'
```

PHP will increment a *letter*. Useful occasionally, surprising always.

### 5. ✅ Booleans & Comparison

```php
$test = true;
$test = false;

$test = true && true;    // AND — both must be true
$test = true || false;   // OR  — either will do
$test = !false;          // NOT — flips it
```

**Comparison operators produce booleans:**

```php
$test = 10 > 5;     // true
$test = 10 < 5;     // false
$test = 10 < 10;    // false
$test = 10 >= 10;   // true
$test = 10 <= 10;   // true
$test = 10 != 5;    // true
$test = 10 !== 5;   // true
```

**The important pair, again:**

```php
$test = 10 == '10';    // true  — loose: compares value, converts types
$test = 10 === '10';   // false — strict: value AND type must match
```

Same for `!=` versus `!==`. **Prefer the strict versions** — they do what you meant.

**These combine, with the usual precedence and brackets:**

```php
$test = true && false || (true && !true);
```

### 6. 📚 Arrays

```php
$test = [1, 2, 'word', true];   // mixed types are fine
var_dump($test[2]);             // 'word' — indexes start at 0
```

**Reading and writing by index:**

```php
$test[2] = 'asdasda';    // overwrite an existing slot
$test[4] = 'new value';  // write to a specific index
```

**Appending, two ways:**

```php
$test[] = 'another value';          // shorthand: next free index
array_push($test, 'pushed value');  // the function form
```

**Associative arrays — string keys instead of numbers:**

```php
$test = [
    'name' => 'Kaspar',
    'age'  => 33,
    1,
    3,
    'vzcxzzxc',
    100 => 'new value',
    5,
];
var_dump($test['name']);   // reached by name, not position
```

Note what's happening here: **named keys and automatic numeric keys coexist in one array**, and
setting an explicit `100 =>` affects where the automatic numbering continues from. `var_dump()`
on the whole array is the way to see what you actually built.

**Nested arrays** — an array whose elements are arrays:

```php
$test = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
];
var_dump($test[1][2]);   // 6 — second row, third item
```

Index twice: first picks the row, second picks the item within it.

## ✅ Takeaways

1. **`$x -= 1`, `$x++`, `$x **= 2`** — every operator has a compound form. Learn them once.
2. **`%` is remainder, not percent.** `$n % 2` is the even/odd test.
3. **`.` joins strings, not `+`.**
4. **Single quotes are literal, double quotes interpolate** `$variables` and `\n`.
5. **Use `===` and `!==`.** `10 == '10'` is true and that will bite you.
6. **`$arr[] = x` appends**, string keys make an associative array, and index twice for nested.
7. **Nothing prints until you `var_dump()` it.**
