### 1. 🧹 An empty welcome page

`routes/web.php` returns the `welcome` view for `/`. Laravel's default welcome page is over 200
lines, most of it an inlined Tailwind build and its own markup. All of it went, leaving a bare
HTML page:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    @vite('resources/css/app.css')
</head>
<body>
    <button class="bg-blue-400">Hello</button>
</body>
</html>
```

`@vite(...)` is the Blade directive that loads our CSS through Vite. Without it the page has no
styles at all, which was exactly the first problem when trying the class. The project already
has Tailwind installed and imported in `resources/css/app.css`:

```css
@import 'tailwindcss';
```

With `composer run dev` running, Vite rebuilds the CSS whenever a class is added in a view.

### 2. 🌬️ Tailwind: only utility classes

Bootstrap gave us ready-made components: `btn btn-primary` and you have a button. Tailwind does
not. It has small utility classes, one job each (a background colour, padding, rounded corners,
a hover colour), and a component is built out of many of them. `bg-blue-400` above is one.
Tailwind's documentation lists the classes for everything: colours, spacing, borders, states.

### 3. 🔘 The exercise: Bootstrap's primary button in Tailwind

Recreate Bootstrap's `btn btn-primary` as closely as possible using **only Tailwind classes**:

- the same colours, padding, font and rounded corners,
- the hover state (darker),
- the active state (while it is pressed),
- the focus state: the glowing ring that appears when you reach the button with Tab.

It will not be 100% identical, but it should be close. This was given as homework, and it shows
quickly why people like component libraries.

## ✅ Takeaways

1. **`@vite('resources/css/app.css')` in the head**, or Tailwind classes do nothing.
2. **Tailwind has utilities, not components**: one small job per class.
3. **A button has states**: hover, active and focus all need their own classes.
