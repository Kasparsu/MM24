## 🗂️ Topics Covered

### 1. 🔗 References: `&`

Normally assigning copies the value:

```php
$num1 = 1;
$num2 = &$num1;   // pointer: pass by reference
$num1 = 2;
var_dump($num1, $num2);   // 2 and 2
```

The `&` makes `$num2` **point at the same storage** as `$num1` rather than taking a copy.
Change one, the other changes: they are two names for one value.

---

### 2. 🧬 Objects Are Different: `clone`

This is the part that surprises people:

```php
$box1 = new Box();
$box1->width = 1;

$box2 = clone $box1;   // clone to get a genuinely new object
$box2->width = 2;

var_dump($box1, $box2);   // widths 1 and 2: independent
```

**Simple values are copied on assignment. Objects are not.** `$box2 = $box1` would give you
two variables pointing at *the same box*: change one, you change both, exactly like the `&`
example above but without asking for it.

**`clone` is how you say "actually give me a separate copy".**

### 3. 🔒 Visibility: `public`, `private`, `protected`

Properties and methods each carry a visibility keyword:

```php
class Box {
    public $width;        // anyone can touch it
    private $height;      // only this class
    protected $length;    // this class and its children

    public bool $isOpen = false;          // typed property
    public bool $hasBeenOpened = false;
}
```

| Keyword | Reachable from |
|---|---|
| `public` | Anywhere: outside code, this class, subclasses |
| `private` | **Only inside this class** |
| `protected` | This class **and classes that extend it** |

Note `public bool $isOpen`: properties can be **typed**, the same as function parameters.

**Why hide anything?** Because then you control how it changes:

```php
public function setHeight(int $height) {
    if ($height > 0) {
        $this->height = $height;
    }
}

public function getHeight() {
    return $this->height;
}
```

`$height` is `private`, so the only way in is `setHeight()`, which **refuses a negative
value**. A public property can be set to nonsense by anyone; a private one with a setter
cannot. These accessor methods are the classic **getter/setter** pair.

---

### 4. 👪 Inheritance: `extends`

A class can build on another:

```php
class MetalBox extends Box {
    public $weight;

    public function mass() {
        return $this->volume() * $this->weight;
    }

    public function test2() {
        var_dump($this->height);   // ❌ private in Box, not accessible here
    }
}

$metal1 = new MetalBox();
```

`MetalBox` gets **everything public and protected from `Box`**: `$width`, `open()`,
`close()`, `volume()`, and adds `$weight` and `mass()`. Note `mass()` calling `$this->volume()`:
an inherited method, used as if it were its own.

> ⚠️ **This is where visibility becomes concrete.** `test2()` tries to read `$this->height`,
> which is `private` in `Box`. A child class **cannot** see it. `protected` would have worked.
> That is precisely the difference between the two keywords.

### 5. 🧵 Traits: Sharing Behaviour Without Inheritance

Inheritance gives you **one** parent. When two unrelated classes need the same behaviour, a
**trait** is the tool:

```php
trait HasSmell {
    public $smell;
    public function sniff() {
        return 'Smells like ' . $this->smell;
    }
}

trait MakesSound {
    public $sound;
    public function noise() {
        return $this->sound;
    }
}

class Cat {
    use MakesSound;
}

class Dog {
    use HasSmell, MakesSound;
}
```

A trait is a block of properties and methods **pasted into** whichever class `use`s it. `Cat`
makes a sound; `Dog` makes a sound *and* has a smell. Neither extends anything, and you can
`use` **several** traits in one class: unlike `extends`.

> 💡 Rule of thumb: `extends` for "is a kind of", traits for "can also do this".

## ✅ Takeaways

1. **`&` makes two names for one value.**
2. **Objects don't copy on assignment**: use `clone` when you want a separate one.
3. **`private` = this class only, `protected` = this class and its children, `public` = anyone.**
4. **Getters and setters let you validate**: a private property can't be set to nonsense.
5. **`extends` gives you one parent** and everything non-private from it.
6. **Traits share behaviour across unrelated classes**, and you can use several.
