### 1. 🏷️ Namespaces

New directory, one class per file:

```
src/
  Router.php               →  App\Router
  DB.php                   →  App\DB
  Controllers/
    PublicController.php   →  App\Controllers\PublicController
```

```php
<?php
namespace App;

class Router {

}
```

```php
<?php
namespace App\Controllers;

class PublicController {

}
```

**A namespace is a surname for a class.** Without one, every class in the project — and every
class in every library you ever install — shares one global pool of names, and two `Router`
classes collide. `App\Router` and `Vendor\Router` can coexist.

**Note the convention:** the namespace mirrors the directory structure, with `src/` as the
root. `src/Controllers/PublicController.php` → `App\Controllers\PublicController`. That
correspondence is what makes the next part possible.

**Using them:**
```php
use App\Router;                              // then just Router
use App\Controllers\PublicController as PC;  // aliased, because the full name is long

$router = new App\Router();                  // or fully qualified, no `use` needed
```

### 2. ⚙️ Autoloading

Writing `require_once` for every class gets old immediately:

```php
// require_once __DIR__ . '/../src/Router.php';
// require_once __DIR__ . '/../src/DB.php';
```

Replaced by one registration:

```php
spl_autoload_register(function ($class) {
    $class = substr($class, 4);              // drop the "App\" prefix
    $class = str_replace('\\', '/', $class); // namespace separators → directories
    require_once __DIR__ . "/../src/$class.php";
});
```

**How it works:** when PHP meets a class name it doesn't know, it calls the registered
function, hands it the full name, and lets it load the file. `App\Controllers\PublicController`
→ strip `App\` → swap `\` for `/` → `src/Controllers/PublicController.php`.

**So `new App\DB()` just works** — no `require` anywhere. Add a file in the right place with
the matching namespace and it's available.

> 💡 This is the mechanism Composer's autoloader uses. Writing it once by hand is the best way
> to stop it being magic.

### 3. 🚏 A Real Router

The `switch` becomes a class that **collects** routes and then **matches** one:

```php
namespace App;

class Router {
    private static $routes = [];

    public static function getRoutes() {
        return self::$routes;
    }

    public static function addRoute($path, $action) {
        self::$routes[] = ['path' => $path, 'action' => $action];
    }

    public function __construct(private $path) {

    }

    public function match() {
        foreach (self::$routes as $route) {
            if ($route['path'] === $this->path) {
                return $route;
            }
        }
        return false;
    }
}
```

**Two different kinds of member in one class — this is the payoff of the `static` lesson:**

| Member | Why it's what it is |
|---|---|
| `private static $routes` | One route table for the whole application, not per-object |
| `static addRoute()` | Registering a route shouldn't need an instance |
| `__construct(private $path)` | *This* request has *a* path — per-object data |
| `match()` | Instance method: compares the shared table against this request's path |

**Registering routes** — the action is a closure, so a route is a path plus a piece of code:

```php
use App\Router;

Router::addRoute('/', function () {
    $title = 'World';
    $posts = [ /* … */ ];
    include __DIR__ . '/../views/index.php';
});

Router::addRoute('/us', function () {
    $title = 'U.S';
    $posts = [ /* … */ ];
    include __DIR__ . '/../views/us.php';
});
```

**Then dispatch:**
```php
$router = new App\Router($_SERVER['REQUEST_URI']);
$match = $router->match();
if ($match) {
    call_user_func($match['action']);
} else {
    echo 404;
}
```

`call_user_func()` runs the stored closure. **Adding a page no longer means editing the
dispatcher** — you call `addRoute()` once more and you're done.

## ✅ Takeaways

1. **A namespace is a surname** — it stops your `Router` colliding with everyone else's.
2. **Namespace should mirror directory structure.** That's what makes autoloading a
   two-line trick.
3. **`spl_autoload_register`** loads classes on demand. No more `require_once` lists.
4. **Static = shared by the class, instance = about this request.** The `Router` uses both, on
   purpose.
5. **A route is a path plus a callable.** Registering one is a function call, not an edit to a
   `switch`.
