### 2. 🔀 `if` / `else` / `else if`

The first of the two big structures every language has. If you remember it from JavaScript,
this is the same thing.

An **`if`** takes a condition that evaluates to **true or false**: exactly the comparisons
from the previous lesson, and runs the block in braces only when it's true.

```php
$num = 10;

if ($num > 5) {
    var_dump('Bigger');
}
```

**Adding a fallback:**
```php
if ($num > 5) {
    var_dump('Bigger');
} else {
    var_dump('Smaller');
}
```

**Testing several conditions in order:**
```php
if ($num > 5) {
    var_dump('Bigger');
} else if ($num < 5) {
    var_dump('Smaller');
} else {
    var_dump('Equal');
}
```

Conditions are checked top to bottom; the first true one wins and the rest are skipped. `else`
catches everything left over.

> 💡 The block can be one line or a hundred: anything between the braces runs as a unit.

### 3. 🎛️ `switch` / `case`

When you're comparing **one value against many specific options**, a chain of `else if` gets
tedious. `switch` is the tidier form.

```php
$i = 1;

switch ($i) {
    case 1:
        var_dump('üks');
        break;
    case 2:
        var_dump('kaks');
        break;
    case 3:
    case 4:
        var_dump('kolm neli');
        break;
    case 5:
        var_dump('viis');
    case 6:
        var_dump('kuus');
        break;
    default:
        var_dump('dunno');
}
```

**Three behaviours worth reading carefully in that example:**

| Pattern | What happens |
|---|---|
| `case 1:` … `break;` | Normal: match, run, stop |
| `case 3:` `case 4:` | **Deliberate** fall-through: both values run the same block |
| `case 5:` with **no** `break` | Falls into `case 6` and runs that too: usually a bug |
| `default:` | Runs when nothing matched |

**`break` is what stops execution.** Without it, PHP keeps running *into the following cases*.
Stacking empty cases (3 and 4) uses that on purpose; forgetting it after `case 5` does not.

![Forgot break](https://api.memegen.link/images/fine/_/Forgot_break_in_a_switch_case.png)

### 4. 🔁 `for` Loops

```php
for ($i = 0; $i < 10; $i++) {
    var_dump($i);
}
```

Three parts, separated by semicolons:

1. **Start**: `$i = 0`, run once at the beginning
2. **Condition**: `$i < 10`, checked before each pass; loop continues while true
3. **Step**: `$i++`, run after each pass

**Counting down**, just reverse all three:
```php
for ($i = 9; $i >= 0; $i--) {
    var_dump($i);
}
```

**The step doesn't have to be ±1:**
```php
for ($i = 2; $i < 1_000_000; $i *= 2) {
    var_dump($i);
}
```
Doubling each time. Note `1_000_000`: **underscores as digit separators**, purely for
readability. PHP ignores them.

### 5. ⏳ `while` and `do…while`

`while` checks a condition and repeats while it holds:

```php
$time = time();
$n = 0;
while ($time + 1 > time()) {
    $n++;
}
var_dump($n);
```

A neat demonstration: run for one second and count the iterations. The number is startlingly
large: a useful gut-feel for how fast this all actually is.

**When the condition is false from the start:**
```php
while (false) {
    var_dump('WHILE');   // never runs
}

do {
    var_dump('DO');      // runs once, then checks
} while (false);
```

**That's the whole difference:** `while` tests *before*, `do…while` tests *after*, so a
`do…while` body always runs **at least once**.

```php
// while(true) {
//
// }
```
Left commented out on purpose, `while (true)` with nothing to stop it is an **infinite loop**
that hangs the program. `Ctrl+C` in the terminal is how you get out.

![Infinite loop](https://api.memegen.link/images/mordor/One_does_not_simply/exit_a_while(true)_loop.png)

### 6. 🍎 `foreach`: Looping Over Arrays

The one you'll use most in PHP. It walks an array without you managing an index:

```php
$fruits = ['Apple', 'Cherry', 'Banana'];

foreach ($fruits as $fruit) {
    var_dump($fruit);
}
```

Read it as "for each element of `$fruits`, call it `$fruit` and do this". No start, no
condition, no step, and no chance of running off the end.

**When you need the key as well:**
```php
foreach ($fruits as $key => $fruit) {
    var_dump($fruit, $key);
}
```

For a plain list the key is the numeric index; for an associative array it's the string key,
which is what makes `foreach` the natural way to walk the associative arrays from last lesson.

> 💡 `var_dump()` takes several arguments at once: `var_dump($fruit, $key)` dumps both.

## ✅ Takeaways

1. **`git pull` before you start**, and make sure you're in the project directory.
2. **`if` runs a block when a condition is true**; `else if` chains stop at the first match.
3. **`switch` needs `break`.** Without it execution falls into the next case: deliberate for
   stacked cases, a bug everywhere else.
4. **`for` is start / condition / step**, and the step can be anything, including `*= 2`.
5. **`do…while` always runs at least once**, `while` may run zero times.
6. **`foreach` is the right tool for arrays**, and `as $key => $value` when you need both.
7. **`while (true)` with no exit hangs.** `Ctrl+C`.
